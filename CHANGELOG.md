# Senbazuru — CHANGELOG

## v20 — 2026-10-13

- Бумажные самолётики в небе во всех режимах — роль облаков: несколько штук на разной глубине плывут по ветру, ближние оставляют лёгкий след, изредка один делает мёртвую петлю. Нарисованы кодом (контур из трёх граней бумаги), цвета — кремовая бумага и светлые васи-оттенки.

## v19 — 2026-10-13

- Персонаж фона: большой бумажный журавль с обложки рядом с полем, 11 состояний — покой, дремлет, старт вращения, следит за барабанами, ждёт скаттер, кивает скаттеру, радуется выигрышу (две силы), празднует табличку выигрыша, бонус, поникает без выигрыша.
- Графика — готовая (обложка), движения кодом; на маленьких экранах без свободного места персонаж скрыт.
- Ручки для тестов: `__game.hero(name, level)`, `__game.heroBox`.

## v18 — 2026-10-13

- Живая рамка: раз в 8 с по периметру пробегает золотая искра и зажигает искры в углах; при показе выигрыша бегут две искры без пауз; при ожидании скаттера рамка пульсирует золотом.
- Живой фон: лепестки сакуры (базовый режим), светлячки (фриспины), золотая фольга (супербонус); журавлики в небе, когда нет фон-видео; гирлянды по краям качаются.
- Всё кодом, без новой графики; подробности — ART.md, раздел «Анимации рамки и фона».

## v17 — 2026-10-12

- Idle-анимации одинаковых символов идут синхронно: все копии символа на поле (и липкие вайлды) двигаются в одной фазе. У разных символов фазы по-прежнему разные.

## v16 — 2026-10-12

- Idle-анимации всех 10 символов на поле: у каждого своя петля в стилистике оригами (качка кораблика, порыв вертушки, блик звезды, взмах веера с лепестками, крылья бабочки, волна карпа с пузырьками, хвост лисы, парящий журавль, блик вайлда, свет фонаря). Только кодом из существующих спрайтов, без новой графики. Подробности — ART.md, раздел «Анимации символов на поле».
- Плавный набор и затухание анимации при остановке и старте барабана.
- Отключение: `prefers-reduced-motion` или `?idle=0`.
- Ручки для автотестов: `__game.board(cols)` (задать видимое поле), `__game.idle(on)`.
- Репозиторий синхронизирован со сборкой v15 из `dist/` (до этого в main был v11).
